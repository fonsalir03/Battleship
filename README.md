#### Lessons Learned

- Setting up Jest for use with ES6
- More in depth understanding of git such as viewing changes between commits, conventional commit messages, rebasing, amending, and force pushing
- Using webpack to bundle the project in different modes (production and development)
- More about css positioning and subgrid
- Callbacks
- You can use an arrow function when using a class method as a callback to avoid "loosing this"
